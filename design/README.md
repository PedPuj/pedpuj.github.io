# The design spec

`handoff.md` is the specification this site was built from — produced in Claude
Design and delivered on 6 September 2026 as part of the *Bedro design system
canvas* bundle.

It is kept here because it is the source of truth for every colour, size,
spacing value and interaction on the site. If you ever want to change how
something looks, read the relevant section first: most of the apparent
oddities (the emptiness, the single grid, the missing accent on Japan, the
absence of a contact form) are deliberate.

The rest of the original bundle — an HTML canvas of every artboard plus the
JavaScript that made those artboards demonstrable — was prototype scaffolding
and is not part of this site.
